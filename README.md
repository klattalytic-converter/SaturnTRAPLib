# SaturnTRAPLib

This is a passion project that I work on in my spare time, nicknamed TRAPlib, or "Truly Ridiculous Accelerator Processing" Library. Despite the name, I don't know if a full library will ever be released, but that is the goal. For now this is more of a hypothetical yk. 

This repository is for research into using the Sega Saturn's other processors for 3D acceleration, inspired by the TRIP accelrator project at Sega. I am hoping to find a way to use the CD block's SH-1 for acceleration without any external hardware, but a simple card to allow this to happen might be needed.
